# GitHub Upload Guide for Non-Developers

This is the easiest browser-only upload path.

## 1. Create a public GitHub repository

1. Go to GitHub and sign in.
2. Click the `+` button in the top-right corner.
3. Click `New repository`.
4. Repository name: `plotlock-cdr`
5. Description: `Spoilerless IP prediction markets powered by Story CDR.`
6. Visibility: `Public`
7. Do not add a README if you plan to upload this full folder directly, because this ZIP already includes one.
8. Click `Create repository`.

## 2. Upload the project files

1. On the empty repo page, click `uploading an existing file`.
2. Open the unzipped `plotlock-cdr` folder on your computer.
3. Drag all files and folders into GitHub.
4. Wait until all files finish uploading.
5. At the bottom, type commit message: `Add PlotLock CDR hackathon project`.
6. Click `Commit changes`.

## 3. Submit the GitHub link

After upload, copy the browser URL. It should look like:

```text
https://github.com/YOUR_USERNAME/plotlock-cdr
```

Paste that into the CDR Hackathon form.

## 4. Optional: make sure judges can inspect it

The repo should be public. If you make it private instead, add `jacob-tucker` as a collaborator before submitting.
