# 해봄 웹버전 주요 화면

원페이저의 `HAEBOM_logo_primary_horizontal.png`를 그대로 사용한 연구자용 웹 워크스페이스다.

## 1. 홈 · AI 연구 시작

- 연구계획서와 선행연구 업로드
- 지도교수 피드백 붙여넣기
- 자연어로 연구 목적 설명
- 최근 양적·질적 연구 이어하기

## 2. AI 연구 브리프

- 연구질문, 설계, 결과변수, 분석 후보 구조화
- 선행연구 원문과 검증척도 연결
- 표본수 산정과 IRB 등 미확인 항목 표시

## 3. 조건·자극 스튜디오

- 실험 조건을 한 화면에서 비교
- 의도한 조작 외 언어·시각 차이 탐지
- 자극물 출처와 수정 이력 관리

## 4. 측정 연결 지도

- 연구 개념과 설문 문항 연결
- 클릭 등 실제 행동 이벤트 연결
- 데이터 필드와 누락 항목 확인

## 5. 검토·승인

- 출처, 척도, 혼입 변인, 표본수, IRB, 개인정보 체크
- 연구자 승인 전 게시 차단
- 승인 시 연구 버전과 변경 이력 고정

## 6. 모집·실행

- 웹 링크와 QR 배포
- 토스는 보조 참여 채널로 표시
- 익명 Participant ID 생성
- 설문 응답과 행동 로그 연결

## 디자인 원칙

- 원페이저 로고 원본을 재가공하지 않고 이미지 자산으로 직접 사용
- 토스처럼 넓은 여백, 짧은 문장, 한 화면 한 과업
- 흰색 바탕, 해봄 블루, 연구 안전을 나타내는 민트 색상
- AI 초안과 연구자 승인 상태를 색상과 문구로 명확히 구분
- 데스크톱, 태블릿, 모바일 반응형 구성
